# Computer Engineering Coursework

A growing collection of **computational assignments, implementations, and problem-solving exercises** completed throughout my B.Sc. in Computer Engineering at **Shahid Beheshti University**.

This repository documents the breadth of topics I have worked with during my undergraduate studies—from low-level programming and digital circuit simulation to algorithms, software design, databases, and artificial intelligence.

Rather than separating every university exercise into an individual repository, I maintain this repository as a continuously expanding archive of practical coursework across different areas of Computer Engineering.

---

## 🎯 Purpose

My main projects and research work are maintained in dedicated repositories.

This repository serves a different purpose: to document the broader technical foundation developed throughout my Computer Engineering education.

The exercises collected here involve different programming paradigms, languages, tools, and problem domains, and reflect experience with:

- Algorithmic problem solving
- Procedural and object-oriented programming
- Data structures and graph/tree algorithms
- Algorithm design techniques
- Artificial intelligence and search
- Evolutionary computation
- Database querying
- Networking and concurrency concepts
- Digital circuit design and simulation
- Software design and organization

All material included here consists of **computer-based assignments and implementations**, rather than written/theoretical homework.

## 🧩 Topics Covered

### Basic Programming

Early programming exercises focused on building a strong foundation in procedural programming and computational thinking.

The assignments cover:

- Variables and primitive data types
- Conditional logic
- Iterative algorithms
- Arrays and matrices
- String manipulation
- Functions
- Recursive problem solving
- Pointers
- Dynamic memory allocation
- Basic numerical and algorithmic problems

Implemented primarily using **C and C++**.

---

### Advanced Programming

The Advanced Programming coursework moves from procedural programming toward larger and more structured software systems.

Topics represented in the repository include:

- Object-Oriented Programming
- Classes and object relationships
- Encapsulation
- Inheritance
- Polymorphism
- Interfaces and reusable abstractions
- Design patterns
- Regular expressions
- Functional constructs
- Networking-related exercises
- Shared-resource and concurrency-related problems
- Git and version-control exercises
- Small multi-class applications

The majority of these assignments were implemented in **Java**.

---

### Data Structures

These assignments focus on implementing and manipulating fundamental structures rather than relying solely on built-in abstractions.

Examples include:

- Linked lists
- Sorted linked lists
- Trees
- Tree traversal
- Recursive processing
- Graph-like representations
- Subtree computations
- Query-based problems over structured data

Implementations use both **Java and C++**.

---

### Design & Analysis of Algorithms

This section contains algorithmic programming problems solved using several major algorithm-design paradigms.

Topics include:

- Greedy algorithms
- Dynamic programming
- Backtracking
- Divide and conquer
- Depth-first exploration
- Optimization problems
- Ordering and scheduling problems
- Path and state-space problems

Solutions are implemented primarily in **C++**, with some exercises in **Python**.

The emphasis of these assignments is not only obtaining a correct result, but identifying an appropriate algorithmic strategy for each problem.

---

### Artificial Intelligence

The AI coursework contains both classical AI algorithms and optimization-based computational exercises.

#### Classical Search

Implementations include:

- Uniform Cost Search (UCS)
- A* Search
- Priority-queue-based graph exploration
- Cost-based path finding
- Graph construction from data

Some exercises operate on traffic-dependent graph costs derived from structured datasets.

#### Genetic Algorithms & Image Segmentation

A more extensive assignment applies a **Genetic Algorithm to image segmentation**, including:

- Population initialization
- Genome representation
- Tournament and roulette-wheel selection
- Multiple crossover strategies
- Mutation
- Elitism
- Early stopping
- Fitness evaluation
- HSV-based image segmentation
- F1 / Dice-based evaluation
- IoU-related evaluation
- Training and validation results
- Visualization of evolutionary progress

This work uses tools including:

- Python
- NumPy
- Pandas
- OpenCV

---

### Database Systems

The database coursework consists of executable SQL assignments covering progressively more advanced relational operations.

Topics include:

- Basic `SELECT` queries
- Filtering
- Sorting
- Aggregation
- Relational data retrieval
- Multi-condition queries
- Intermediate SQL operations

The exercises are organized by topic rather than maintained as separate repositories.

---

### Digital Integrated Circuits

This section represents the hardware-oriented side of my Computer Engineering coursework.

Assignments include transistor-level circuit simulation and analysis using:

- **HSPICE**
- **AvanWaves**

The repository contains circuit descriptions, simulation configurations, generated simulation results, and waveform outputs used to evaluate circuit behavior.

This coursework complements the software-focused sections of the repository by providing experience closer to the hardware and circuit-design layer of computing.

## 🧠 Problem-Solving Focus

One of the main goals of maintaining this repository is to preserve the progression of my problem-solving experience across different areas of computing.

The problems here range from manipulating memory with pointers and implementing recursive algorithms to designing data structures, solving optimization problems, querying relational databases, implementing AI search algorithms, and simulating transistor-level circuits.

The technologies naturally change from course to course, but the common theme is the same:

**understanding a problem, selecting an appropriate abstraction or algorithm, and implementing a working solution.**
